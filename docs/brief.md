# 프로젝트 브리프: sh-video-editor

## 한 줄 정의

영상을 자르고 붙이고 자막·효과·음악을 얹어 내보내고 싶은 일반 사용자를 위해, CapCut·VLLO·Clideo 수준의
쉬운 편집 경험을 전문가급 편집 엔진 위에 얹어 데스크톱(Windows 먼저)과 웹 브라우저 양쪽에서 똑같이 쓰게
하는 영상·오디오 편집기.

## 문제와 사용자

- **문제**: 쉬운 편집기(CapCut·VLLO)는 모바일 중심이고 워터마크·구독·클라우드 업로드가 따라붙는다.
  전문가 편집기(Premiere·DaVinci)는 배우기 어렵고 무겁다. "내 PC 와 브라우저에서, 내 파일을 올리지 않고,
  10분 안에 결과물이 나오는 편집기"가 비어 있다.
- **사용자 유형**:

| 유형                                        | 이 앱에서 하는 일                                                        |
| ------------------------------------------- | ------------------------------------------------------------------------ |
| 일반 사용자(병원 홍보·교육 영상, 개인 영상) | 클립 가져오기, 자르기·순서 바꾸기, 자막·음악·전환 넣기, MP4 로 내보내기  |
| 템플릿 사용자                               | 미리 만든 템플릿(인트로·SNS 세로 영상·슬라이드쇼)에 내 클립만 끼워 완성  |
| 제작자(이성현)                              | 엔진을 개선하고 효과·템플릿을 추가, 에이전트(MCP·CLI)로 엔진을 자동 검증 |

## 핵심 시나리오 (v1.0 에 반드시 되어야 하는 것)

"누가 무엇을 해서 무엇을 얻는다" 문장으로, 우선순위 순.

1. 사용자가 영상·사진·음악 파일을 끌어다 놓고 타임라인에서 자르고(razor) 순서를 바꾸고 길이를 조절해
   편집본을 만든다. 미리보기가 프레임 단위로 정확히, 끊김 없이 재생된다.
2. 사용자가 자막(텍스트)과 제목을 넣고 글꼴·색·위치·등장 시간을 정한다. 음성 인식으로 자막 초안을 자동 생성한다.
3. 사용자가 전환(디졸브·와이프 등)과 영상 효과(밝기·색·블러·속도), 스티커·오버레이를 클립에 적용하고
   키프레임으로 움직임을 준다.
4. 사용자가 배경음악과 효과음을 얹고 볼륨·페이드·덕킹(음성 구간 자동 낮춤)을 조절한다.
5. 사용자가 해상도·비율(16:9, 9:16, 1:1)·화질 프리셋을 골라 MP4(H.264/AAC)로 내보낸다. 진행률과 취소가 된다.
6. 사용자가 프로젝트를 저장하고 다시 열며, 앱이 죽어도 자동 저장본에서 복구한다.
7. 사용자가 같은 편집기를 브라우저에서 열어 파일을 서버에 올리지 않고(WASM 엔진, 로컬 파일) 편집·내보내기한다.

## 제약

- **플랫폼/형태**: 데스크톱 앱(Windows 인스톨러 먼저, macOS 는 다음) + 웹(브라우저, 오프라인 동작, 파일 업로드 없음).
  데스크톱과 웹은 같은 화면 코드를 쓴다.
- **엔진**: 외부 영상 라이브러리(ffmpeg 등)를 링크하지 않는다. 순수 Rust 엔진을 저장소 안에 소스로 두고 개선한다.
  성능이 중요하다(미리보기 지연, 내보내기 속도, 메모리).
- **기간/리듬**: 혼자 개발. 첫 마일스톤은 며칠 안에 "클립 넣고 자르고 내보내기"가 되는 것.
- **비용**: 유료 API·클라우드 없음. 음성 인식도 로컬 모델.
- **기타**: 개인 저작물(UNLICENSED). 가져온 오픈소스 엔진(MIT/Apache-2.0)의 고지 의무는 NOTICE 로 지킨다.
  Adobe·CapCut 등 타사 아이콘·에셋·상표 사용 금지.

## 성공 기준

- "이것만 되면 v1.0" (사용자 확정 2026-10-14): 1080p 클립 3개를 넣어 자르고, 자막과 배경음악을 넣고,
  전환 하나를 적용해 MP4 로 내보낸 결과가 Windows 데스크톱과 Chrome 브라우저 양쪽에서 같은 화질·같은 길이로 나온다.
- 제품 표시 이름: **SH Video Editor** (저장소·산출물 파일명은 sh-video-editor).

## 범위 밖 (이번에 안 하는 것)

- 클라우드 저장·계정·협업·공유 링크 (웹도 로컬 파일만)
- 모바일 앱(iOS/Android)
- VST3/AU 오디오 플러그인 호스팅, 멀티캠, 전문가용 컬러 그레이딩 워크스페이스
- AI 생성(텍스트로 영상 만들기, 음성 합성). 음성 인식(STT)은 범위 안
- Premiere `.prproj` 등 타사 프로젝트 파일 읽기
