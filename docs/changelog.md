# 체인지로그 (릴리스 단위)

사람용 요약 - 릴리스(버전 승격·배포) 단위로만 기록한다. 세부 이력은 `session-log.md`.

## v0.1.10 (2026-10-15)

- 내보내기가 빨라짐: 1080p 18초 기준 WebM 129초에서 71초, HEVC 237초에서 106초, AV1 314초에서 146초(크기·화질 같음)
- AV1 이 목표 비트레이트를 약 10% 넘던 것 수정, 느린 형식을 1080p 로 고르면 예상 시간 안내
- 전환이 클립 끝 프레임을 반복하면 "핸들 자동으로 다듬기" 버튼
- SNS 카드로 WebM·HEVC·AV1 을 고르면 형식에 맞는 비트레이트(YouTube 1080p WebM 20 에서 8 Mbps)
- 크게 키운 움직이는 스티커가 선명함, 흔들림 줄이기가 미디어를 바꾼 뒤 다시 분석함
- 웹: 큰 파일 탐색 뒤 메모리 667MB 에서 474MB, 데모 장면 모두 60ms 안, 내려받기 14.7MB 에서 14.0MB, 새 프로젝트 Alt+N
- 좁은 화면 상태 줄에서 이름이 잘리던 것 수정, 문제 보고에 최근 편집 기록

## v0.1.9 (2026-10-15)

- 굵은 글씨가 선명해짐: UI 글꼴을 돋움에서 맑은 고딕 우선으로(sh-design-system 0.1.2), 가짜 굵게 끄기
- 데스크톱 창 제목이 앱 위쪽 어두운 줄 가운데에 표시되어 메뉴와 한 덩어리로 이어짐(Windows 흰 제목 줄 없음)
- 일시는 어디서나 `yyyy-mm-dd hh:mm:ss`, 괄호 일시는 줄바꿈 때 통째로 다음 줄로
- 토스트: 한글 낱말 중간에서 끊기지 않음, 작은 X 닫기, 엔진 영어 알림 17종 한국어로, 같은 알림 두 번 안 뜸, Untitled 는 제목 없음
- 자막 탭 버튼과 제목 겹침, 라벨 두 줄 접힘 수정. 미디어 패널 탭 여섯 개가 한 줄에. 템플릿 색 배경 이름 한국어

## v0.1.8 (2026-10-15)

- 웹에서도 자동 자막(whisper tiny·base, 모델은 첫 사용 때 한 번 받아 브라우저에 보관)
- whisper-small 이 30초 창 안의 둘째 문장을 버리던 문제 수정
- 웹: 가져온 미디어를 브라우저 저장소에 보관해 새로고침·복구 뒤 "미디어 다시 연결" 없이 열림
- 키프레임 마커를 엔진에서 직접 읽어 실행 취소·다시 열기 뒤에도 정확함
- 전환이 클립보다 길면 클립 안으로 줄이고, 핸들이 모자라면 상태 줄에 알림
- 빨라진 것: 웹 데모 영상 프레임 최대 4배(Aurora 237ms 에서 56ms), 음정 유지 미리보기 소리 2.5~13배, 데스크톱 렌더러 1.4MB 에서 925KB
- 정리: 안 쓰는 export 약 160개, 중복 도우미·대화상자 통합, 자동 자막 칸이 편집본 없을 때 멈추던 문제 수정

## v0.1.7 (2026-10-15)

- AV1 (mp4) 내보내기 형식과 프리셋 2종 (소프트웨어 인코더, H.264 의 약 10배 느림, 파일은 절반 이하)
- 움직이는 스티커 10종 (Lottie, 투명 배경으로 반복 재생). 자기 Lottie(.json/.lottie) 파일도 미디어로 가져오기
- 내 템플릿: 지금 편집본을 템플릿으로 저장, 미디어 슬롯에 고른 항목을 넣어 만들기, 이름·설명 바꾸기, .json 내보내기·가져오기
- 흔들림 줄이기·장면마다 자르기가 백그라운드 작업으로 돌고 상태 줄 작업 칸에 진행률·취소가 보임 (웹에서도 화면이 멈추지 않음)
- CI: 모바일(390) e2e 도 PR 을 막음

## v0.1.6 (2026-10-14)
