# SH Video Editor 사용법

영상·사진·음악 파일을 넣고 자르고 자막·전환·음악을 얹어 MP4 로 내보내는 방법입니다. 이 문서가 사용법의 원천(SSOT)이며, 앱의
도움말 > 사용 안내는 이 파일을 그대로 보여 주고 README 의 "시작하기" 는 이 문서의 요약입니다. 문구는 화면의 라벨과 글자 그대로
같고, 각 절 끝의 "코드" 줄이 그 동작을 정하는 파일입니다.

용어: 타임라인에 클립을 늘어놓은 결과 하나를 **편집본** 이라고 부릅니다(다른 편집기의 시퀀스에 해당). 프로젝트 하나에 편집본을
여러 개 둘 수 있고, 미디어 패널의 트리에서 "편집본" 표시가 붙은 항목이 그것입니다.

## 1. 5분 안에 첫 영상

### 1.1 미디어 가져오기 또는 데모 영상 넣기

- 데스크톱: 미디어 패널의 **가져오기** 버튼, 메뉴 **파일 > 미디어 가져오기...**, 또는 탐색기에서 파일을 미디어 패널로 끌어다 놓기.
- 웹: 메뉴 **파일 > 미디어 가져오기...** 로 브라우저 파일 선택 창을 엽니다(웹에서는 끌어다 놓기가 되지 않습니다). 파일은 브라우저 안에서만 읽고 서버에 올리지 않습니다. 가져온 파일은 잠시 뒤 브라우저 안 저장소에 복사해 두므로, 새로고침하거나 복구한 뒤에도 파일을 다시 고르지 않아도 됩니다(1.6 절).
- 파일이 없으면 미디어 패널의 **데모 영상** 버튼(바다 노을, 오로라, 도시의 밤, 사막 모래언덕, 플라스마, 숲) 또는 **파일 > 데모 영상 넣기 > 전부 넣기**. 데모 영상은 엔진이 만드는 생성 영상이며 소리도 들어 있습니다.
- 가장 빠른 길: 편집본이 없을 때 타임라인 자리에 보이는 안내 카드의 **데모 영상 넣기** 버튼(또는 **파일 > 데모 편집본**)을 누르면 데모 영상 6개를 넣고 차례로 이어 붙인 "데모 편집본" 이 바로 열립니다.

코드: `packages/editor/src/features/media/MediaPanelView.tsx`, `features/shortcuts/actions.ts`(importMedia), `features/onboarding/edition.ts`(createDemoEdition)

### 1.2 타임라인에 넣기

편집본이 아직 없어도 됩니다. 처음 넣는 항목의 해상도·프레임 수로 편집본이 자동으로 만들어지고 이름은 프로젝트 이름(처음에는 "제목 없음")을 따릅니다.

- 미디어 항목을 타임라인의 트랙으로 **끌어다 놓기**. 놓을 자리에 세로선이 보입니다. 편집본이 없으면 안내 카드 위에 놓아도 됩니다.
- 미디어 항목을 **더블클릭**(또는 Enter): 편집본 끝에 덧붙입니다.
- 항목을 고르고 미디어 패널의 **타임라인에 넣기** 버튼, 우클릭 메뉴의 **타임라인에 넣기**, 또는 **파일 > 타임라인에 넣기**.
- 영상은 V1 트랙에, 영상에 붙은 소리는 A1 트랙에 같이 놓이며 둘은 연결되어 함께 움직입니다(클립 이름 앞의 연결 아이콘). 소리만 있는 항목은 A1 에 놓입니다.
- 다른 편집본을 새로 시작하려면 **파일 > 새 편집본(빈 타임라인)** 또는 항목 우클릭 > **새 편집본으로 열기**. 미디어 트리의 편집본 항목을 더블클릭하거나 우클릭 > **열기** 로 다른 편집본으로 바꿉니다.

코드: `features/onboarding/edition.ts`(addToTimeline), `features/timeline/Timeline.tsx`(onDrop), `features/media/MediaTree.tsx`

### 1.3 자르기, 순서, 길이

- 플레이헤드 옮기기: 눈금자나 빈 레인을 누르거나 끌기, 미리보기의 스크러버, 좌우 화살표(한 프레임), Home/End.
- **자르기**(도구 줄 버튼 또는 Ctrl+K): 플레이헤드 자리에서 나눕니다. 클립을 선택해 두면 그 클립만, 선택이 없으면 플레이헤드 아래 모든 클립을 자릅니다. **타임라인 > 모든 트랙 자르기**(Ctrl+Shift+K)는 선택과 상관없이 모든 트랙을 자릅니다.
- 순서 바꾸기: 클립 몸통을 끌어 옮깁니다(다른 트랙으로도). 끌 때 클립 가장자리·플레이헤드·0 에 달라붙습니다(스냅, S 로 끄고 켬).
- 길이: 클립 양 끝의 핸들을 끌어 줄이거나 늘립니다(원본 길이 안에서, 프레임 단위). 소리가 연결된 클립은 소리도 같이 다듬어집니다.
- 지우기: 클립을 고르고 **삭제** 버튼 또는 Delete. 뒤 클립까지 당겨 빈틈을 없애려면 **편집 > 리플 삭제**(Shift+Delete) 또는 도구 줄의 **리플** 을 켜 두고 삭제합니다.
- 여러 클립 고르기: Shift+클릭(추가), Ctrl+클릭(토글), **편집 > 전체 선택**(Ctrl+A). 빈 레인을 누르면 선택이 풀립니다.

코드: `features/timeline/store.ts`(razorAtPlayhead, moveClips, trimClip, deleteSelection), `features/timeline/geometry.ts`(스냅)

### 1.4 재생과 탐색

- 미리보기 패널의 재생 버튼 또는 Space. J 는 뒤로, L 은 앞으로 재생이며 거듭 누르면 1x, 2x, 4x 로 빨라지고 K 는 정지입니다.
- **재생 배율** 콤보(0.25x, 0.5x, 1x, 1.5x, 2x, 4x) 또는 **보기 > 재생 배율**. 상태 줄에 지금 배율이 보입니다.
- **재생 화질** 콤보(자동, 전체, 1/2, 1/4): 재생하는 동안 미리보기를 그리는 해상도입니다. **자동** 은 재생이 계속 늦을 때만 한 단계 낮추고 다시 빨라지면 올립니다. **1/2**, **1/4** 는 늘 그 해상도로 그려 무거운 편집본도 끊김 없이 봅니다. 정지하면 언제나 화면 크기에 맞춰 선명하게 그립니다. 고른 값은 다음에 켤 때도 남습니다(데스크톱·웹 모두 이 컴퓨터 브라우저 저장소).
- 데스크톱 앱은 재생 위치보다 앞 프레임을 엔진이 미리 그려 두고, 정지해 있는 동안 다음 재생의 첫 프레임과 곧 나올 클립의 디코더도 준비합니다. 그래서 처음 재생해도 자르기 지점에서 끊기지 않습니다. 재생을 눌렀는데 준비가 0.3초를 넘으면 타임코드 옆에 "준비 중" 이 잠깐 보입니다(1초를 넘기면 그냥 출발합니다). 자세한 동작과 실측은 `docs/guides/playback.md`.
- 소리: 스피커 버튼(M)으로 끄고 켜고, 옆의 **마스터 볼륨** 슬라이더로 미리보기 소리 크기를 정합니다. 내보내기에는 영향이 없습니다.
- 타임코드는 "현재 / 전체" 이며 형식은 시:분:초:프레임입니다.

코드: `features/monitor/MonitorPanel.tsx`, `features/monitor/controller.ts`, `features/monitor/quality.ts`, `features/audio/AudioToolbar.tsx`

### 1.5 내보내기 (MP4, HEVC, AV1, WebM)

1. **파일 > 내보내기...**(Ctrl+M).
2. 위의 **화면 비율** 막대에서 16:9, 9:16, 1:1, 4:5 를 바꿀 수 있고(편집본 자체가 바뀝니다. 3.5 절), **SNS 프리셋** 카드(YouTube 1080p, Shorts, Reels, Instagram 정사각, YouTube 4K)를 누르면 프리셋이 그 값으로 맞춰집니다. 카드의 비트레이트는 형식을 따라갑니다: H.264 값 그대로, HEVC 는 0.6배, AV1 은 0.5배, WebM 은 0.4배(같은 화질에 필요한 양이 적어서입니다). 형식을 바꾸면 카드의 Mbps 표시도 바로 바뀝니다.
3. **프리셋**: 1080p 가로 (1920 x 1080), 720p 가로 (1280 x 720), 세로 9:16 (1080 x 1920), 정사각 1:1 (1080 x 1080), 편집본 원본 크기. **형식** 은 **H.264 (mp4)**, **HEVC (mp4)**, **AV1 (mp4)**, **WebM (VP9 + Opus) (webm)** 중 고릅니다. HEVC 를 고르면 같은 `.mp4` 에 H.265 로 담아 같은 화질에서 파일이 H.264 의 절반 정도가 되고(iPhone·최신 TV 호환, 인코딩은 더 느림), 프리셋은 HEVC 용(1080p, 720p, 9:16, 1:1)으로 바뀝니다. AV1 을 고르면 같은 `.mp4` 에 AV1 로 담아 파일이 HEVC 만큼 작고 로열티가 없지만(Chrome·Edge·Firefox·Android 가 재생, Windows 는 AV1 비디오 확장이 필요) 인코딩이 가장 느리며, 프리셋은 AV1 용(1080p, 720p, 9:16, 1:1)으로 바뀝니다. WebM 을 고르면 프리셋이 WebM 용(1080p, 720p, 9:16, 1:1)으로 바뀌고 저장 경로의 확장자가 `.webm` 이 됩니다. WebM 은 브라우저에서 바로 재생되고 파일이 작지만 인코딩이 느립니다(`docs/guides/webm-export.md`).
4. **저장 위치** 의 **찾아보기** 로 파일 이름을 정합니다. **결과** 줄에 해상도·fps·길이·비트레이트가 보입니다. HEVC·AV1·WebM 을 1080p 이상으로 고르면 그 아래에 H.264 보다 몇 배 오래 걸리는지(데스크톱 기준 WebM 약 2배, HEVC 약 3배, AV1 약 4배)와 720p 안내가 보입니다. 브라우저에서는 이보다 더 걸립니다.
5. **내보내기** 를 누르면 진행률과 남은 시간이 보이고 **취소** 로 멈출 수 있습니다. 끝나면 "내보냈습니다: 경로 (N초 걸림, 크기)" 알림이 뜹니다.

웹에서는 저장 위치 대신 파일 이름만 정하고, 끝나면 브라우저가 파일을 내려받습니다(WASM 이라 데스크톱보다 몇 배 느립니다).

코드: `features/export/ExportDialog.tsx`, `features/export/presets.ts`, `features/ratio/RatioBar.tsx`, `features/ratio/SnsPresets.tsx`

### 1.6 저장, 열기, 자동 저장 복구

- **파일 > 최근 프로젝트**: 최근에 열거나 저장한 프로젝트 10개. 첫 화면 안내 카드에도 같은 목록이 보입니다. 웹은 브라우저 안(OPFS)에 저장한 프로젝트가 여기에 남습니다.
- **파일 > 저장**(Ctrl+S), **다른 이름으로 저장...**(Ctrl+Shift+S): 프로젝트 파일(`.fcproj`)에 미디어 경로·편집본·설정을 저장합니다. 미디어 파일 자체는 복사하지 않으므로 원본 파일을 옮기면 열 때 "찾을 수 없는 미디어 N개" 라고 알립니다.
- **파일 > 열기...**(Ctrl+O). 저장하지 않은 변경이 있으면 "저장할까요?" 대화상자가 먼저 뜹니다(취소, 저장하지 않음, 저장). **파일 > 새 프로젝트**(Ctrl+N, 웹은 Alt+N)도 같습니다.
- 상태 줄 오른쪽에 프로젝트 이름과 저장 상태(저장 안 함, 저장됨, 수정됨)가 보이고 창 제목에 "(수정됨)" 이 붙습니다. 데스크톱은 창 맨 위 제목 줄이 앱과 같은 어두운 띠로 메뉴바와 이어지며, 띠를 끌어 창을 옮기고 두 번 눌러 최대화합니다.
- 자동 저장(데스크톱): 작업 중 변경을 앱 데이터 폴더에 주기적으로 남깁니다. 앱이 꺼지거나 멈춘 뒤 다시 켜면 **저장하지 않은 변경 복구** 대화상자가 뜨며 **복구**(되살림. 저장하면 원본 파일에 씁니다), **나중에**(다음 실행 때 다시 안내), **버리기** 중에 고릅니다.
- 웹에서는 **브라우저에 저장**(이 브라우저의 사이트 저장소, 서버에 올리지 않음) 또는 **내 컴퓨터로 받기**(.fcproj 내려받기)로 저장하고, 열기는 브라우저 안 목록 또는 **내 컴퓨터에서 고르기**입니다. 자동 저장은 30초마다 브라우저 안에 남기며 다시 열면 복구를 묻습니다(6 절).
- 웹의 미디어 보관: 가져온 영상·소리·사진(스티커 포함)은 가져오고 1.5초쯤 뒤부터 브라우저 안 저장소(OPFS)에 복사됩니다. 다음에 페이지를 열면 같은 이름으로 다시 연결되어, 저장한 프로젝트나 복구본이 **미디어 다시 연결** 없이 열립니다. **파일 > 열기...** 대화상자 아래에 "보관한 미디어 N개 (크기), 사이트 사용량 / 한도" 가 보입니다. 저장 공간이 모자라거나 복사가 끝나기 전에 탭을 닫은 파일은 보관되지 않으며, 그 파일을 쓰는 프로젝트를 열면 예전처럼 **미디어 다시 연결** 대화상자가 떠서 같은 이름의 파일을 다시 고르면 됩니다. 어느 프로젝트·복구본에도 쓰이지 않고 하루가 지난 보관 파일은 다음 시작 때 지워집니다.

코드: `features/project/store.ts`, `features/project/RecoveryDialog.tsx`, `features/project/ConfirmDialog.tsx`, 웹 미디어 보관 `features/project/web-media.ts`·`apps/web/src/engine.worker.ts`

## 2. 화면 구성

위에서 아래로 메뉴바, 본문(미디어 패널, 미리보기, 속성 패널), 타임라인, 상태 줄입니다. 창 폭이 900px 이하이면 세 패널이 한 열로 쌓이고 패널 사이 크기 조절 선은 숨습니다.

### 2.1 메뉴바

| 메뉴     | 항목                                                                                                                                                                                                                                                                              |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

### 2.5 타임라인

- 제목 줄: "타임라인 - 편집본 이름" 과 플레이헤드 타임코드.
- 도구 줄: **자르기**, **삭제**, **리플**, **삽입**, **스냅**, **축소**, **확대**, **맞춤**, **실행 취소**, **다시 실행**, 오른쪽 끝에 지금 줌(px/s).
  - 리플: 삭제·트림 때 뒤 클립을 당깁니다. 삽입: 놓기·이동 때 겹치는 클립을 밀어냅니다(끄면 덮어씁니다). 스냅: 끌 때 클립 가장자리와 플레이헤드에 맞춥니다.
- 트랙 머리: 위에서 V3, V2, V1, 그 아래 A1, A2, A3. 각 트랙에 **잠금**(편집·놓기 금지), 영상 트랙에 **숨김**, 음성 트랙에 **음소거**. 트랙이 모자라면 **타임라인 > 트랙 추가**(V 와 A 를 하나씩) 또는 빈 레인 우클릭 > **트랙 추가**.
- 눈금자: 누르거나 끌면 플레이헤드가 따라옵니다. 눈금은 프레임 경계에 맞춘 타임코드입니다.
- 줌: 확대 +, 축소 -, 전체 보기 \, Ctrl+휠(커서 아래 시간이 고정됩니다). 세로·가로 스크롤은 휠과 스크롤바.
- 클립 블록: 영상 클립에는 첫 프레임 썸네일, 음성 클립에는 파형이 그려집니다. 속도를 바꾼 클립에는 "2x", "역" 같은 배지가 붙습니다. 꺼진 클립·숨긴 트랙·음소거 트랙의 클립은 흐리게 보입니다.
- 끌기: 몸통 끌기 = 이동(다른 트랙 가능), 양 끝 핸들 = 길이. **Alt 를 누른 채 끌면** 연결된 소리(또는 영상)는 두고 그 클립만 움직입니다. 핸들에 마우스를 올리면 "끌어서 길이 조절. Alt 를 누르면 소리/영상만" 안내가 보입니다.

## 3. 작업별 절차

### 3.1 자막 넣기

텍스트 클립(장면마다 글자를 얹는 방식)과 자막 트랙(시간표가 있는 자막 목록) 두 가지가 있습니다.

텍스트 클립:

1. 플레이헤드를 글자가 나올 자리에 두고 속성 패널 도구 줄의 **텍스트 추가**(T), **큰 제목**, **하단 자막 띠**, **코너 라벨** 중 하나를 누릅니다. 5초짜리 텍스트 클립이 영상 트랙에 생기고 **텍스트** 탭이 열립니다.
2. **내용** 칸에 글을 씁니다. 여러 줄은 Enter, 적용은 Ctrl+Enter 또는 다른 곳 클릭.
3. **글꼴** 묶음: 글꼴(Pretendard 번들, 한글·영문), 굵기(Regular, Bold), 크기, 색, 정렬(왼쪽, 가운데, 오른쪽).
4. **위치** 묶음: 9칸 버튼으로 모서리·가운데에 붙이거나 X, Y 를 직접 넣습니다. 미리보기에서 글자를 끌어도 됩니다.
5. **외곽선**, **배경 상자**, **그림자** 는 "사용" 을 켜면 두께·색·불투명도·여백·거리·흐림 칸이 나옵니다.
6. **시간** 묶음: 등장(초)과 길이(초). 타임라인에서 클립을 끌어도 같습니다.

자막 트랙(SRT):

1. 속성 패널의 **자막** 탭(편집본이 있으면 항상 보입니다). **자막 추가** 를 누르면 플레이헤드 위치에 자막 한 줄이 생기고, 목록에서 시작(초), 끝(초), 내용을 고칩니다. **삭제** 로 한 줄을 지웁니다.
2. 이미 만든 자막 파일이 있으면 **SRT 가져오기**(데스크톱은 파일 대화상자, 웹은 브라우저 파일 선택. `.srt`, `.vtt`). **SRT 내보내기** 는 데스크톱에서 파일로 저장하고 웹에서는 내려받기가 됩니다.
3. **스타일** 묶음(글꼴, 크기, 색, 배경 상자, 외곽선, 위치(아래, 가운데, 위), 정렬)은 트랙 전체에 적용됩니다. **트랙 삭제** 는 자막 트랙을 통째로 지웁니다.

자막 자동 생성(음성 인식)은 자막 탭의 **자동 자막** 절에서 합니다. 모델, 언어를 고르고 **선택 클립으로 자막 만들기** 또는 **편집본 전체로 자막 만들기** 를 누릅니다. 처음 쓰는 모델은 크기·출처·라이선스를 보여 주는 동의 대화상자가 뜨고, 동의하면 한 번만 내려받습니다(이후에는 인터넷 없이 씁니다). 인식한 글(전사)은 3.12 절처럼 문장 단위 편집에도 씁니다.

- 데스크톱: 모델 tiny·base·small. 모델은 앱 데이터 폴더에 보관합니다.
- 웹(최신 Chrome·Edge): 모델 tiny·base(small 은 브라우저 메모리에 맞지 않아 빠집니다). 모델은 그 브라우저의 사이트 저장소에 보관하므로 다른 브라우저에서는 다시 받습니다. 인식은 편집과 따로 돌아 그동안에도 미리보기·편집이 됩니다. 30초 말소리를 base 로 약 17초(재생 시간의 0.6배)에 인식합니다. 사이트 저장소나 공유 메모리를 쓸 수 없는 브라우저에서는 안내 문구만 보입니다.
- 클립 하나가 30초보다 길면 30초씩 나눠 인식합니다. 모델이 문장 하나를 끝내고 멈춰도 그 뒤에 말소리가 남아 있으면 그 자리부터 이어서 인식합니다.

코드: `features/text/TextTab.tsx`, `features/text/presets.ts`, `features/text/CaptionsTab.tsx`, `features/text/captions-store.ts`, `features/text/srt.ts`

### 3.2 전환 넣기, 길이 바꾸기

1. 미디어 패널의 **전환** 탭. 디졸브, 검정으로 페이드, 흰색으로 페이드, 밀기, 슬라이드, 휩, 줌 블러, 글리치, 빛 번짐, 시계 와이프, 직선 와이프, 크로스 줌.
2. 카드를 타임라인의 두 클립이 맞닿은 곳(편집점)으로 **끌어다 놓습니다**. 편집점 가까이에서만 받습니다. 클립의 맨 앞이나 맨 끝에 놓으면 페이드 인·아웃이 됩니다.
3. 또는 클립을 선택하고 카드를 **더블클릭**(카드에 포커스를 두고 Enter 를 눌러도 같습니다). 도구 줄의 **더블클릭 위치**(양쪽, 앞, 뒤)가 어느 경계에 넣을지 정합니다.
4. 길이: 타임라인의 전환 블록 양 끝 핸들을 끌거나, 블록을 선택한 뒤 속성 패널 **전환** 탭의 **길이**(프레임) 칸에 숫자를 넣습니다. **종류** 콤보로 다른 전환으로 바꾸고 **반전** 으로 방향을 뒤집습니다.
5. **정렬**(앞, 가운데, 뒤) 버튼으로 전환을 컷의 어느 쪽에 둘지 바꿉니다(한쪽 편집점의 페이드는 정해져 있습니다). **삭제** 로 전환을 지웁니다(실행 취소로 되돌릴 수 있습니다).
6. 전환은 클립보다 길 수 없습니다. 더 길게 넣거나 늘리면 클립 안에 들어가는 만큼으로 줄이고 상태 줄에 "클립 길이에 맞춰 N프레임으로 줄였습니다" 가 붙습니다. 가운데 정렬이면 짧은 쪽 클립 길이의 두 배까지입니다.
7. 자르지 않은 클립 사이처럼 컷 너머에 쓸 영상이 없으면, 그 구간은 앞 클립의 마지막 화면이나 뒤 클립의 첫 화면을 반복해서 보여 줍니다(검게 비지 않습니다). 이때 상태 줄에 "미디어가 모자라 N프레임은 끝 화면을 반복합니다" 가 붙고, **핸들 자동으로 다듬기** 버튼이 있는 알림이 뜹니다. 버튼을 누르면 앞 클립 끝과 뒤 클립 처음을 모자란 만큼 잘라(리플이라 두 클립은 계속 붙어 있고 뒤의 클립들이 당겨집니다) 전환이 실제 장면을 씁니다. 실행 취소 한 번으로 되돌릴 수 있습니다. 여러 클립에 한꺼번에 넣었으면 알림 하나로 모두 다듬습니다. 사진·색 배경·데모 영상은 반복할 일이 없습니다.

코드: `features/transitions/TransitionGallery.tsx`, `features/transitions/timeline-drop.ts`, `features/transitions/TransitionInspector.tsx`, `features/transitions/catalog.ts`

### 3.3 효과, 필터, 색 보정, 비교 보기

- 영상 클립을 선택하면 속성 패널에 **효과** 탭과 **색** 탭이 보이고, 미디어 패널의 **필터** 탭이 살아납니다.
- 효과 탭: **기본** 묶음(불투명도, 크기, 회전, 위치)은 모든 영상 클립에 있습니다. **효과 추가** 메뉴(밝기와 대비, 흐림, 선명하게, 비네팅, 모자이크, 흑백, 색조, 노이즈, 그림자)로 효과를 붙이면 목록에 줄이 생기고, 체크로 켜고 끄기, **초기화**, **삭제** 가 됩니다. 슬라이더를 끄는 동안은 실행 취소 한 단계로 묶입니다. 같은 항목은 **클립 > 효과 추가** 메뉴에도 있습니다.
- 색 탭: **기본 보정**(노출, 대비, 채도, 온도, 틴트). 슬라이더를 움직이면 색 보정 효과가 붙습니다. **초기화**(또는 **클립 > 색 보정 초기화**)로 지웁니다.
- 필터 탭: 폴더(시네마틱, 필름, 흑백, 보정, 편집기 프리셋)별 카드. 클릭하면 적용(앞 필터는 교체), 같은 카드를 더블클릭하거나 **필터 해제**(또는 **클립 > 필터 해제**)로 지웁니다. 썸네일은 선택 클립 첫 프레임의 근사 색 견본입니다.
- **비교(원본 보기)**: 세 곳 모두에 있는 토글이며 켜는 동안 효과를 잠시 꺼서 원본을 보여 줍니다. 켜져 있는 동안은 효과 값을 바꿀 수 없습니다.

코드: `features/effects/EffectsTab.tsx`, `features/effects/ColorTab.tsx`, `features/effects/FilterGallery.tsx`, `features/effects/catalog.ts`

### 3.4 속도, 역방향, 프리즈 프레임

1. 클립을 선택하고 속성 패널 **속도** 탭, 또는 **클립 > 속도, 길이...**(Ctrl+R, 우클릭 메뉴에도 있음).
2. 슬라이더(0.1x ~ 10x) 또는 배속 칸, 빠른 선택 0.5x, 1x, 2x, 4x. **보간** 은 프레임 샘플링(빠름), 프레임 블렌딩(부드럽게), 옵티컬 플로(가장 부드럽게, 느림).
3. **역방향 재생** 을 켜면 거꾸로 갑니다. **음정 유지(소리 음높이 그대로)** 를 켜면 빠르게 또는 느리게 해도 소리가 높아지거나 낮아지지 않습니다(0.5x~2x 에서 가장 깨끗하고, 역방향에는 적용되지 않습니다). **리플(길이가 바뀌면 뒤 클립을 밀거나 당김)** 을 켜면 길이 변화만큼 뒤 클립이 따라옵니다.
4. "적용 후 길이" 줄을 확인하고 **적용**. 타임라인 클립에 "2x", "0.5x 역" 같은 배지가 붙습니다.
5. **이 프레임 고정**: 플레이헤드를 선택 클립 위에 두고 누르면 그 자리에 2초짜리 정지 화면이 끼워집니다.
6. 구간마다 속도를 다르게 하려면 같은 탭의 **속도 곡선**(3.14 절).

코드: `features/speed/SpeedTab.tsx`, `features/speed/SpeedForm.tsx`, `features/speed/model.ts`, `features/shortcuts/SpeedDialog.tsx`

### 3.5 세로(9:16) 영상으로 바꾸고 Shorts 프리셋으로 내보내기

1. **타임라인 > 화면 비율...**. **비율** 에서 세로 9:16(1080 x 1920, Shorts, Reels, TikTok)을 고릅니다. 가로 16:9, 정사각 1:1, 세로 4:5 도 있습니다.
2. **클립 맞춤**: 채우기(빈 곳 없이 화면을 채우고 넘치는 부분은 잘립니다) 또는 맞추기(클립 전체가 보이고 남는 곳은 검게 둡니다). **적용** 하면 편집본 크기가 바뀌고 영상 클립 전부가 새 화면에 맞춰집니다. 실행 취소로 되돌릴 수 있습니다.
3. 텍스트 클립 위치는 자동으로 옮겨지지 않으니 미리보기에서 다시 끌어 맞춥니다.
4. **파일 > 내보내기...** 에서 **SNS 프리셋** 의 **Shorts, Reels**(1080 x 1920) 카드를 누르고 저장 위치를 정한 뒤 **내보내기**. 내보내기 대화상자 위의 **화면 비율** 막대에서 비율을 바로 바꿀 수도 있습니다.

### 3.6 배경음악 넣고 볼륨, 페이드, 덕킹

1. 미디어 패널 **음악** 탭. **파일에서 가져오기** 로 음악 파일을 넣거나, **생성 음원** 목록의 **추가**(데모 영상의 소리, "바다 노을 분위기 음악" 등)로 시험용 음원을 만듭니다.
2. **프로젝트의 소리** 목록에서 **넣기** 를 누르면 플레이헤드 자리의 비어 있는 음성 트랙에 놓입니다(빈 트랙이 없으면 하나 더합니다). 행을 타임라인으로 끌어다 놓아도 됩니다.
3. 음악 클립을 선택하면 속성 패널 **오디오** 탭:
   - **볼륨**: 슬라이더(-48 ~ +12 dB)와 **음소거** 체크. 여러 소리 클립을 골랐으면 함께 적용됩니다.
   - **페이드**: 페이드 인·페이드 아웃 길이를 고르고 **적용**. 옆에 "현재 N초" 가 보입니다. **클립 > 소리 페이드 인(1초)**, **소리 페이드 아웃(1초)** 은 1초 고정의 빠른 길입니다.
   - **음성 구간 자동 낮춤**: 음악 클립에서 **음성 구간 자동 낮춤(덕킹)** 을 누르면 같은 시간에 겹치는 다른 소리 클립에서 말소리가 나는 동안 음악 볼륨이 낮아집니다. **유형**(지정 안 함, 대화(음성), 음악, 효과음, 배경음)으로 각 클립의 역할을 알려 주면 더 정확합니다. 결과는 상태 줄에 "음성 구간 N개를 찾아 키프레임 N개를 만들었습니다" 로 보입니다.
4. 음성 클립 블록의 파형으로 소리 크기를 눈으로 확인합니다. 트랙 머리의 **음소거** 는 그 트랙 전체를 끕니다.

코드: `features/audio/MusicLibrary.tsx`, `features/audio/AudioInspector.tsx`, `features/audio/ducking.ts`, `features/audio/ClipWaveform.tsx`

### 3.7 영상과 따로 녹음한 소리 싱크 맞추기

자동(권장):

1. 영상 클립과 따로 녹음한 소리 클립을 각각 자기 트랙에 놓습니다. 두 클립 모두에 같은 소리(현장음, 박수 등)가 들어 있어야 합니다.
2. 영상 클립을 클릭하고 Ctrl+클릭으로 소리 클립을 함께 선택합니다.
3. **클립 > 소리로 싱크 맞추기**(우클릭 메뉴에도 있음). 영상 클립을 기준으로 소리 클립이 옮겨지고 "N개를 옮겨 싱크를 맞췄습니다 (+N프레임)" 알림이 뜹니다. 공통 소리가 뚜렷하지 않으면 경고와 함께 결과를 확인하라고 알립니다.

파형으로 직접 맞추기:

1. 타임라인을 **확대**(+ 또는 Ctrl+휠)해 두 클립의 파형이 또렷이 보이게 합니다. 박수나 큰 소리가 나는 봉우리를 찾습니다.
2. **스냅**(S)을 꺼서 가장자리에 달라붙지 않게 한 뒤 소리 클립 몸통을 끌어 봉우리를 영상 소리의 봉우리에 맞춥니다.
3. 재생해 확인하고 어긋나면 클립을 끌어 미세하게 조정합니다. 재생 배율 0.25x, 0.5x 로 느리게 들으면 판단하기 쉽습니다.
4. 맞춘 뒤 두 클립을 함께 선택하고 **클립 > 소리 분리, 다시 연결**(Ctrl+L)로 연결해 두면 이후 함께 움직입니다. 원래 영상에 붙어 있던 소리는 3.8 절처럼 분리해 끄거나 지웁니다.

코드: `features/context-menu/clip-actions.ts`(synchronizeByAudio, toggleLink), `features/audio/ClipWaveform.tsx`, `features/audio/peaks.ts`

### 3.8 소리만 따로 자르기, 조절하기

- 영상 클립과 그 소리는 연결되어 있어 하나를 자르거나 옮기면 같이 움직입니다. 한쪽만 다루는 방법 두 가지:
  - **Alt 를 누른 채 끌기**: 그 순간만 연결을 무시하고 끌고 있는 클립(이동 또는 길이)만 바뀝니다.
  - **클립 > 소리 분리, 다시 연결**(Ctrl+L, 우클릭 메뉴에서는 소리 분리(연결 해제)): 연결을 끊어 이후 계속 따로 움직입니다. 같은 항목으로 다시 잇습니다.
- 소리 클립만 선택하고 **자르기**(Ctrl+K)를 누르면 그 클립만 잘립니다(연결된 상태라면 영상도 같이 잘립니다).
- 소리 클립을 끄려면 우클릭 > **음소거**(Shift+E) 또는 오디오 탭의 **음소거**, 지우려면 Delete. 트랙 머리의 **음소거** 는 트랙 전체.
- 영상만 남기고 다른 음악을 깔려면: 분리 -> 원래 소리 클립 삭제 -> 3.6 절대로 음악 넣기.

코드: `features/timeline/Timeline.tsx`(Alt 제스처), `features/timeline/store.ts`(moveClips·trimClip 의 linked 옵션), `features/context-menu/clip-actions.ts`

### 3.9 실행 취소, 다시 실행

- **편집 > 실행 취소**(Ctrl+Z), **다시 실행**(Ctrl+Y 또는 Ctrl+Shift+Z), 타임라인 도구 줄의 **실행 취소**, **다시 실행**. 상태 줄에 "실행 취소: 동작 이름" 이 보입니다.
- 타임라인 편집, 미디어 삭제·이름 바꾸기·폴더, 효과·색·속도·전환·비율·자막·텍스트 변경이 모두 되돌려집니다. 재생 위치·줌·패널 크기·미리보기 소리 설정은 편집이 아니라 되돌리지 않습니다.
- 슬라이더를 끄는 동안의 연속 변경은 한 단계로 묶입니다.

코드: `features/timeline/store.ts`(undo, redo), `packages/editor/src/engine/bridge.ts`

### 3.10 소리 깨끗하게 (잡음, 울림 제거, 음성 강조)

말소리가 들어 있는 소리 클립의 잡음과 방 울림을 줄이고 목소리를 또렷하게 합니다.

1. 음성 트랙의 클립을 선택하고 속성 패널 **오디오** 탭의 **음성 깨끗하게** 묶음으로 갑니다.
2. **대상**: 선택 클립 또는 모든 소리 클립. **강도**: 슬라이더로 약, 보통, 강(기본 보통).
3. **음성 깨끗하게** 를 누르면 클립의 오디오 유형이 대화(음성)로 지정되고 잡음 제거, 울림 제거, 음성 강조 세 효과가 한 번에 켜집니다. 상태 줄에 "음성 깨끗하게(보통)를 클립 N개에 적용했습니다 (N초)" 가 보이고, 묶음 오른쪽에 "적용됨(보통)" 이 표시됩니다. 실행 취소 한 단계입니다.
4. **원래대로** 는 세 효과를 끕니다(유형은 남습니다). 강도를 바꾸려면 슬라이더를 옮기고 다시 **음성 깨끗하게**.
5. 음악 클립에는 쓰지 마세요. 음성 강조는 말소리 대역을 올리므로 음악이 얇아집니다.

코드: `features/audio/cleanup.ts`(applyVoiceCleanup, revertVoiceCleanup), `features/audio/AudioInspector.tsx`. 엔진: `essentialSound.setType`, `essentialSound.set`(repair.noise, repair.reverb, clarity.enhance)

### 3.11 소리 크기 맞추기 (라우드니스 정규화)

편집본 전체의 소리를 플랫폼 기준 크기로 맞춥니다.

1. 음성 트랙의 클립을 하나 선택해 **오디오** 탭을 열고 **소리 크기 맞추기** 묶음에서 목표를 고릅니다: **-14 LUFS**(유튜브, 스트리밍), **-16 LUFS**(팟캐스트, 모바일), **-23 LUFS**(방송).
2. **소리 크기 맞추기** 를 누르면 편집본의 모든 소리 클립을 하나씩 재어(통합 라우드니스, BS.1770) 목표와의 차이만큼 클립 게인을 겁니다. 유형이 없는 클립은 대화(음성)로 지정됩니다.
3. 그 뒤 믹스의 정점을 재어 -1 dB 를 넘으면 마스터(Mix) 볼륨을 그만큼 낮춥니다(넘지 않으면 그대로).
4. 결과가 묶음 아래와 상태 줄에 보입니다: "측정 -21.3 LUFS, 게인 +7.3 dB (클립 2개), 정점 -0.4 dB (마스터 -0.6 dB)". 측정은 클립 평균입니다. 엔진이 라우드니스를 재지 못하는 빌드에서는 미리듣기 파형으로 어림하고 "(근사)" 를 붙입니다.
5. 실행 취소 한 단계("소리 크기 맞추기")로 되돌립니다. 마스터 보정은 별도 한 단계입니다.

코드: `features/audio/cleanup.ts`(normalizeLoudness, describeLoudness). 엔진: `essentialSound.autoMatch {target}`, `sequence.normalizeMixTrack {db: -1}`

### 3.12 전사로 편집 (문장 단위로 지우기, 무음, 군말 제거)

말소리를 글로 받은 전사가 있으면 타임라인 대신 글에서 고를 수 있습니다.

1. 먼저 전사를 만듭니다: 자막 탭의 **자동 자막** (3.1 절. 데스크톱과 웹 모두).
2. 속성 패널 **전사** 탭(편집본이 있으면 항상 보입니다). 문장마다 시작 시각, 화자(있으면), 글이 보입니다. 전사가 없으면 안내와 **자막 탭으로** 버튼만 보입니다.
3. 문장 글을 클릭하면 플레이헤드가 그 문장 시작으로 갑니다. 재생 중인 문장은 왼쪽에 띠가 표시됩니다.
4. **검색** 칸에 낱말을 넣으면 맞는 문장이 강조되고 오른쪽에 "N곳" 이 보입니다.
5. 문장 왼쪽 체크로 고릅니다(Shift+클릭은 범위). **지우기** 는 고른 문장들의 시간 구간을 모든 트랙에서 리플 삭제합니다(자막 트랙도 따라 밀립니다). **구간 표시** 는 고른 범위를 인, 아웃 점으로 찍어 재생, 내보내기 범위로 씁니다. **선택 해제** 로 체크를 지웁니다.
6. **자동 정리**: **무음 기준**(초 이상)을 정하고 **무음 자동 제거** 를 누르면 낱말 사이 그 길이 이상의 틈을 양쪽 0.15초만 남기고 잘라 냅니다. **군말** 목록(쉼표 구분, 자막 탭의 목록과 같음)을 고치고 **군말 제거** 를 누르면 그 낱말이 있는 구간을 잘라 냅니다. 결과는 "무음 N곳을 잘랐습니다 (N초)", "군말 N개를 지웠습니다 (N초)".
7. 모두 실행 취소로 되돌릴 수 있습니다. 지우기는 한 단계("문장 지우기")입니다.

코드: `features/transcript/TranscriptTab.tsx`, `features/transcript/store.ts`. 엔진: `transcript.inspect`, `transcript.search`, `transcript.extract`, `transcript.select`, `transcript.removePauses`, `transcript.removeFillers`

### 3.13 장면마다 자르기 (장면 전환 자동 감지)

카메라가 바뀌거나 화면이 확 달라지는 곳을 찾아 클립을 잘라 둡니다. 여러 장면이 한 파일에 든 영상을 정리할 때 씁니다.

1. 영상 클립을 선택하고 **클립 > 장면마다 자르기**(우클릭 메뉴에도 있음).
2. 분석은 엔진의 백그라운드 작업으로 돕니다. 상태 줄 왼쪽 글이 "장면을 찾는 중..." 이 되고 그 오른쪽 **작업 칸** 에 진행 막대와 "장면 찾기 N%", **취소** 버튼이 보입니다(3.19 절). 끝나면 "장면 N곳에서 잘랐습니다 (클립 N개)" 토스트가 뜨고 작업 칸이 사라집니다. 연결된 소리도 같은 자리에서 잘립니다. 찾지 못하면 "장면이 바뀌는 곳을 찾지 못했습니다".
3. **취소** 를 누르면 아무것도 자르지 않고 "장면 찾기를 취소했습니다" 로 끝납니다. 분석은 클립의 모든 프레임을 줄여서 비교하므로 긴 클립은 시간이 걸립니다(웹은 더 느립니다). 자른 결과는 실행 취소 한 단계("장면 전환 감지")로 되돌립니다.

코드: `features/context-menu/clip-actions.ts`(detectScenes), `features/jobs/store.ts`, `features/context-menu/clip-menu.ts`, `features/shortcuts/menu-def.ts`. 엔진: `clip.sceneEditDetection {clips, applyCuts: true, wait: false}` 와 `jobProgress` 이벤트

### 3.14 속도 곡선(램프): 느리게 갔다가 빠르게

1. 영상 클립을 선택하고 속성 패널 **속도** 탭 아래 **속도 곡선** 묶음에서 프리셋 **몽타주**(느리게 시작해 점점 빠르게), **히어로**(빠르게 들어와 가운데서 느려졌다 다시 빠르게), **총알**(거의 멈췄다가 급가속) 중 하나를 누릅니다. 타임라인 클립에 "램프" 배지와 키프레임 마커가 붙습니다.
2. 곡선 편집기(가로 = 클립 시간, 세로 = 0.1x~10x)에서 점을 **끌어** 시각과 속도를 바꾸고, 빈 곳을 **더블클릭** 해 점을 더하고(최대 8개), 점을 고른 뒤 Delete 로 지웁니다. 변경 하나가 실행 취소 한 단계입니다.
3. 클립 길이는 그대로입니다. 평균이 1x 보다 빠르면 소스의 뒷부분을 더 보여 주고, 느리면 끝까지 가지 못합니다. 소리는 곡선을 따르지 않고 원래 속도로 납니다(속도 탭의 배속·역방향과 함께 쓸 수 있습니다).
4. **곡선 지우기** 로 모두 지웁니다.

코드: `features/motion-fx/SpeedCurveSection.tsx`, `features/motion-fx/CurveEditor.tsx`, `features/motion-fx/ramp.ts`, 엔진 `TrackItem::remapped_source_time_at`

### 3.15 배경 지우기(크로마키), 작은 화면(PIP), 오버레이

- **배경 지우기**: 녹색·파란 배경 앞에서 찍은 클립을 선택하고 **효과** 탭의 **배경 지우기(크로마키)** 묶음에서 **배경 지우기 켜기**(기본 녹색) 또는 **스포이트로 켜기** 를 누른 뒤 미리보기에서 지울 배경을 **클릭** 합니다(Esc 로 취소). 켜진 뒤에는 **스포이트** 로 색을 다시 고르고 **키 색**, **허용치**(0~100), **부드러움**(0~100)을 조절합니다. **끄기** 로 뗍니다.
- **오버레이**: 미디어 패널에서 항목을 타임라인의 **V2 레인** 으로 끌어다 놓으면 V1 영상 위에 겹쳐집니다(V2 가 없으면 레인 우클릭 > **트랙 추가**). 배경을 지운 클립을 V2 에 두면 아래 영상 위에 피사체만 남습니다.
- **작은 화면(PIP)**: V2 의 클립을 선택하고 효과 탭 **작은 화면(PIP)** 묶음에서 크기 **25%**, **33%** 를 고른 뒤 **왼쪽 위**, **오른쪽 위**, **왼쪽 아래**, **오른쪽 아래** 중 하나를 누릅니다. 크기와 위치가 한 번에 바뀌고(실행 취소 한 단계), 모션 탭·미리보기 변형 상자로 더 다듬을 수 있습니다. 위치가 애니메이션 중이면 플레이헤드에 키프레임이 됩니다.

코드: `features/motion-fx/EffectsExtras.tsx`, `features/motion-fx/ChromaKeyPickOverlay.tsx`, `features/motion-fx/pip.ts`, `features/motion-fx/chroma.ts`

### 3.16 흔들림 줄이기

1. 흔들리는 영상 클립을 선택하고 **효과** 탭 **흔들림 줄이기** 묶음의 **흔들림 줄이기**(또는 **클립 > 흔들림 줄이기**, 우클릭 메뉴)를 누릅니다.

### 3.17 템플릿: 기본 4종, 내 템플릿 저장·적용·가져오기

미디어 패널 **템플릿** 탭입니다. 위에는 도구 줄(**지금 편집본을 템플릿으로 저장**, **가져오기**), 아래에 **기본 템플릿** 과 **내 템플릿** 절이 있습니다. 어느 카드든 **만들기** 를 누르면 새 편집본이 생깁니다(지금 편집본은 그대로 남습니다). 만든 것 전체는 실행 취소(Ctrl+Z) 한 번으로 되돌아갑니다. 이름은 "<프로젝트 이름> <템플릿 이름>" 입니다.

- **기본 템플릿** 4종: **인트로 제목**(5초 제목 카드, 미디어를 고르면 그 위에), **세로 Shorts 틀**(9:16, 고른 미디어를 꽉 채우고 위 제목·아래 자막 띠), **사진 슬라이드쇼**(사진 3초씩 + 사이마다 디졸브), **엔딩 카드**(감사 문구, 끝에서 검정으로). 미디어가 필요한 템플릿은 미디어 패널에서 항목을 먼저 고릅니다(Ctrl 클릭으로 여러 개). 만든 뒤 제목 클립이 선택되고 텍스트 탭이 열리니 글자를 바로 바꾸세요.
- **지금 편집본을 템플릿으로 저장**: 이름과 설명을 넣고 **저장** 을 누르면 지금 편집본의 구조(편집본 크기·fps, 트랙과 클립의 길이·위치, 텍스트 내용과 모양, 효과와 키프레임, 전환)가 저장됩니다. 영상·사진·음악 클립은 미디어 파일 대신 **슬롯** 이 되고(같은 파일을 쓰던 클립은 슬롯 하나), 카드에 "슬롯 N개" 로 보입니다. 썸네일은 저장 순간 플레이헤드의 화면입니다. 미디어 파일 자체는 저장하지 않습니다.
- **내 템플릿 적용**: 미디어 패널에서 슬롯 수만큼 항목을 고른 뒤(영상·사진은 영상 슬롯에, 음악은 음악 슬롯에, 고른 순서대로) **만들기** 를 누릅니다. 고른 미디어는 화면에 꽉 채워집니다(`clip.fillFrame`). 미디어가 모자라면 그 자리는 비워 두고 알려 주며, 빈 자리에는 미디어 패널에서 항목을 끌어다 넣으면 됩니다. 슬롯이 없는 템플릿(텍스트·색 배경만)은 미디어 없이 만듭니다.
- **카드 메뉴**(우클릭 또는 **메뉴** 버튼): **이름 바꾸기...**, **설명 바꾸기...**, **파일로 내보내기 (.json)**, **삭제**(확인 대화상자). 내보낸 파일은 다른 컴퓨터·브라우저의 **가져오기** 로 다시 넣을 수 있습니다(틀린 파일은 거부하고 이유를 보입니다).
- 저장 위치: 데스크톱은 `%APPDATA%\sh-video-editor\templates\<id>.json` + `<id>.png`, 웹은 브라우저 안(IndexedDB)이라 같은 브라우저에서만 보입니다. 파일 형식은 `docs/guides/timeline.md` 의 "템플릿 JSON" 절.
- 한계: 색 배경(색 매트)의 색은 읽을 수 없어 어두운 기본색으로 저장됩니다. 클립을 끄거나(비활성) 소스 시작점을 옮긴 것(sourceIn)은 저장하지 않습니다. 텍스트 클립이 놓이는 트랙은 엔진이 비어 있는 자리로 고를 수 있습니다.

코드: `features/templates/TemplateGallery.tsx`, `features/templates/catalog.ts`(기본 4종), `features/templates/serialize.ts`(편집본 -> JSON), `features/templates/apply.ts`(JSON -> 커맨드), `features/templates/user-store.ts`, 데스크톱 `apps/desktop/src/main/templates-store.ts`, 웹 `apps/web/src/templates.ts`

### 3.18 스티커 넣기 (정지 20종, 움직이는 10종)

미디어 패널 **스티커** 탭입니다. 분류(말풍선, 화살표, 모양, 배지, 강조, **움직이는 스티커**)마다 카드가 있고, 편집본이 있어야 누를 수 있습니다.

1. 플레이헤드를 스티커가 나올 자리로 옮기고 카드를 **클릭** 합니다. 플레이헤드 위 빈 영상 트랙(없으면 새 트랙)에 **5초** 클립이 생기고, 그 클립이 선택되며 **모션** 탭이 열립니다. 상태 줄에 "스티커를 넣었습니다: 이름" 이 뜹니다.
2. 위치·크기·회전은 **모션** 탭 슬라이더나 미리보기의 변형 상자를 끌어 바꿉니다(3.14 절의 키프레임도 됩니다). 길이는 타임라인에서 클립 끝을 끌어 조절합니다.
3. **움직이는 스티커**(카드 오른쪽 아래에 재생 삼각형 표식): 뛰는 하트, 돌아가는 별, 뛰는 화살표, 깜빡이는 느낌표, 점 세 개, 그려지는 체크, 꽃가루, 흔들리는 말풍선, 반짝이는 반짝임, 떨어지는 핀. 1~2초 길이의 애니메이션이 **클립 길이 동안 반복** 됩니다(클립을 늘리면 계속 반복, 최대 60초). 배경은 투명해서 아래 영상이 비칩니다. 정지 스티커와 똑같이 모션 탭으로 옮기고 키울 수 있으며, 내보내기에도 그대로 들어갑니다.
4. 같은 스티커를 다시 넣으면 미디어 패널에 항목을 더 만들지 않고 이미 가져온 항목을 다시 씁니다. 스티커 클립을 지우는 것은 보통 클립과 같습니다(Delete).

데스크톱과 웹 모두 됩니다. 정지 스티커는 화면이 그림을 PNG 로 바꿔 엔진에 넘기고, 움직이는 스티커는 Lottie(JSON) 파일을 그대로 넘겨 엔진이 매 프레임 벡터로 그립니다. 모션 탭에서 크기를 키우면 보이는 크기로 다시 그려 가장자리가 선명합니다(원래 크기의 4배까지. 크게 키운 스티커는 전체 해상도 미리보기·내보내기에서 프레임마다 조금 더 걸립니다). 자기 Lottie 파일(.json, .lottie)을 **파일 > 미디어 가져오기** 로 넣어도 같은 방식으로 재생됩니다(도형 레이어만 지원, 그림·글자 레이어와 표현식은 건너뜁니다).

코드: `features/stickers/StickerGallery.tsx`, `features/stickers/store.ts`, `features/stickers/catalog.ts`, 에셋 `features/stickers/assets/`(출처 `ATTRIBUTION.md`), 엔진 `crates/lottie`

### 3.19 작업 칸: 오래 걸리는 분석의 진행률과 취소

흔들림 분석(3.16 절)과 장면 찾기(3.13 절)처럼 오래 걸리는 분석은 엔진이 백그라운드 작업으로 돌리고 진행률을 알립니다.

- 진행 중인 작업이 있을 때만 상태 줄(화면 맨 아래) 왼쪽 글 바로 오른쪽에 **작업 칸** 이 생깁니다: 진행 막대, "흔들림 분석 42%" 처럼 이름과 퍼센트, **취소** 버튼.
- 작업이 둘 이상이면 "작업 N개 42%"(가장 느린 것) 와 **목록** 버튼이 보이고, 누르면 작업마다 막대·퍼센트·취소가 있는 목록이 위로 열립니다.
- 내보내기는 자기 대화상자에 진행률이 있어 작업 칸에는 나오지 않습니다.
- 취소하면 엔진이 그 작업을 멈추고 아무것도 바꾸지 않습니다(흔들림 줄이기는 효과까지 뗍니다). 결과는 각 기능이 상태 줄 글과 토스트로 알립니다.
- 웹에서는 작업이 16ms 씩 나뉘어 돌아 화면이 멈추지 않습니다. 탭을 숨기면 브라우저가 타이머를 늦춰 느려질 수 있습니다.

코드: `features/jobs/store.ts`, `features/jobs/JobsPane.tsx`, `features/events/classify.ts`(jobProgress 이벤트). 엔진: `jobs.list`, `jobs.cancel`, `Session::pump_jobs`

## 5. 막힐 때

### 5.1 미리보기가 검게 보일 때

- 편집본이 없거나 비어 있으면 "타임라인이 비어 있습니다." 가 보입니다. 미디어를 타임라인에 넣으세요.
- 플레이헤드가 클립이 없는 구간(클립 사이 빈틈, 편집본 끝)에 있으면 검게 나옵니다. 타임라인에서 클립 위로 옮기세요.
- 영상 트랙 머리의 **숨김** 이 켜져 있거나 클립이 꺼져(우클릭 > **켜기**) 있지 않은지, **비교(원본 보기)** 가 켜져 있지 않은지 확인하세요.
- 특정 파일만 검게 나오면 그 파일이 잘렸거나 지원하지 않는 코덱일 수 있습니다(5.3 절). 데모 영상으로 미리보기 자체가 되는지 먼저 확인하세요.

### 5.2 소리가 나지 않을 때

- 미리보기의 스피커 버튼(M)이 꺼져 있거나 **마스터 볼륨** 이 0 이 아닌지.
- 음성 트랙 머리의 **음소거**, 클립의 **음소거**(오디오 탭 또는 우클릭 메뉴), 오디오 탭의 볼륨이 "꺼짐" 이 아닌지.
- 영상 항목에 소리가 없으면 미디어 패널 아래 요약에 소리 정보가 나오지 않습니다. 소리 클립이 음성 트랙(A1 ~ A3)에 놓여 있는지 확인하세요.

### 5.3 파일을 읽지 못할 때

- 검증한 형식: MP4(H.264, HEVC. 60fps, 가변 프레임, 회전 정보, 4K 포함), MP3, M4A, PNG, JPG. 그 밖의 형식은 가져오기에 실패하거나 소리만 들어올 수 있습니다.
- 끊긴 다운로드처럼 끝이 잘린 MP4 는 오류 없이 검은 프레임으로 나올 수 있습니다. 다른 플레이어에서 재생되는지 먼저 확인하세요.
- 웹에서 끌어다 놓으면 "웹에서는 파일 > 미디어 가져오기로 파일을 고르세요." 라고 안내합니다. 메뉴로 고르세요.
- 프로젝트를 열 때 "찾을 수 없는 미디어 N개" 가 뜨면 원본 파일이 옮겨지거나 지워진 것입니다. 파일을 제자리에 돌려놓고 다시 여세요.

### 5.4 느릴 때

- 상태 줄의 "렌더 N ms, 배율, 건너뜀" 을 보세요. **재생 화질** 이 자동이면 재생이 계속 늦을 때 1/2, 1/4 로 낮춰 끊김을 줄이고, 빨라지면 다시 올립니다. 무거운 편집본은 **1/2** 이나 **1/4** 로 고정하면 처음부터 가볍게 재생합니다. 미리보기 영역을 작게 하면(스플리터) 배율이 낮아져 더 가벼워집니다.
- 재생 배율을 0.5x 로 낮추면 무거운 효과(옵티컬 플로, 흐림)가 걸린 구간도 확인하기 쉽습니다.
- 웹(WASM)은 데스크톱(네이티브)보다 프레임 그리기와 내보내기가 몇 배 느립니다. 긴 영상이나 4K 는 데스크톱 앱을 쓰세요.
- 내보내기 중에는 미리보기가 멈출 수 있습니다. 남은 시간은 대화상자에 보이고 **취소** 로 멈출 수 있습니다.

### 5.5 복구와 재시작

- 앱을 다시 켰을 때 **저장하지 않은 변경 복구** 대화상자가 뜨면 **복구** 를 누르세요. **나중에** 를 고르면 다음 실행 때 다시 안내하고, **버리기** 는 그 복구본을 지웁니다.
- 데스크톱에서 엔진 프로세스가 멈추면 자동으로 다시 시작되며 화면은 새 세션(빈 프로젝트)으로 돌아옵니다. 그 뒤 복구 대화상자나 마지막 저장본으로 이어 가세요.
- 별도의 로그 파일은 없습니다. 상태 줄의 "오류: ..." 와 알림의 문구, 그리고 웹에서는 브라우저 개발자 도구(F12)의 콘솔이 단서입니다. 도움말 > **SH Video Editor 정보** 에 앱 버전과 엔진 버전이 있으니 문의할 때 함께 적어 주세요.

코드: `features/monitor/controller.ts`(프리롤·준비), `features/monitor/quality.ts`(재생 화질), `features/project/store.ts`(복구), `apps/desktop/src/main/engine-supervisor.ts`(엔진 재시작)

### 5.6 문제 보고 파일 (데스크톱)

데스크톱에서 엔진 프로세스가 예기치 않게 종료되면 앱이 자동으로 다시 시작하면서 **문제 보고 파일** 을 하나 남기고, 알림에 **폴더 열기** 버튼을 보입니다. 파일은 서버로 보내지 않습니다. 문의할 때 이 파일을 첨부해 주세요.

- 위치: 사용자 데이터 폴더의 `crash-reports` 아래 `YYYY-MM-DD-HHMMSS.json` (Windows 는 `%APPDATA%\sh-video-editor\crash-reports`). 언제든 도움말 > **문제 보고 폴더 열기** 로 폴더를 열 수 있습니다.
- 내용: 종료 코드와 시그널, 앱·엔진 버전, OS·Electron 버전, 마지막으로 실행한 커맨드 20개(id, 걸린 시간, 성공 여부. 파라미터는 200자까지), 메모리 수치. 영상 파일이나 프로젝트 내용은 들어가지 않습니다(커맨드 파라미터에 적힌 파일 경로는 남을 수 있습니다).
- 웹에는 이 기능이 없습니다(브라우저 콘솔을 보세요).

코드: `apps/desktop/src/main/crash-report.ts`(파일 작성), `apps/desktop/src/main/engine-supervisor.ts`(마지막 커맨드 링 버퍼), `features/events/poller.ts`(알림)

## 6. 데스크톱과 웹의 차이

같은 화면 코드지만 파일을 다루는 방식이 다릅니다. 어느 쪽이든 파일을 서버에 올리지 않습니다.

| 항목                              | 데스크톱(Windows 설치본)              | 웹(브라우저)                                                                              |
| --------------------------------- | ------------------------------------- | ----------------------------------------------------------------------------------------- |
| 엔진                              | 네이티브 프로세스. 멈추면 자동 재시작 | WASM(Worker). 브라우저 안에서만 돌며 느림                                                 |
| 미디어 가져오기                   | OS 파일 대화상자, 끌어다 놓기         | 파일 > 미디어 가져오기... 의 브라우저 파일 선택. 끌어다 놓기 미지원                       |
| 프로젝트 저장·열기                | `.fcproj` 파일                        | 브라우저에 저장(사이트 저장소) 또는 내 컴퓨터로 받기 / 내 컴퓨터에서 고르기               |
| 자동 저장·복구                    | 있음(상태 줄 "자동 저장 켜짐")        | 30초마다 브라우저 안에 저장, 다시 열면 복구 안내                                          |
| 가져온 미디어                     | 원본 파일 경로를 그대로 씀            | 브라우저 안에 복사해 보관(새로고침 뒤 다시 고르지 않음). 공간이 모자라면 다시 고르기      |
| MP4(H.264·HEVC·AV1)·WebM 내보내기 | 저장 위치를 골라 파일로               | 파일 이름만 정하면 끝난 뒤 브라우저가 내려받기                                            |
| SRT 내보내기                      | 파일 대화상자                         | 브라우저 내려받기                                                                         |
| 자동 자막(음성 인식)              | 있음(tiny·base·small, 앱 데이터 폴더) | 있음(tiny·base, 사이트 저장소). 최신 Chrome·Edge                                          |
| 단축키                            | 전부                                  | Ctrl+N 은 브라우저가 가로채 새 창을 엽니다. 새 프로젝트는 Alt+N(메뉴에도 Alt+N 으로 표시) |
| 종료                              | 파일 > 종료                           | 탭 닫기                                                                                   |

코드: `apps/desktop/src/preload/index.ts`, `apps/desktop/src/renderer/main.tsx`, `apps/web/src/bridge.ts`, `packages/editor/src/engine/bridge.ts`(선택 메서드)
