# 스티커 에셋 출처 (features/stickers/assets)

모든 파일은 이 프로젝트를 위해 직접 그린 원작(original work)이며 저작자는 이성현(SeongHyun Lee)이다. 라이선스는 프로젝트
라이선스(루트 `LICENSE`, UNLICENSED)를 따른다. 타사(Adobe, CapCut, VLLO 등) 아이콘·그림을 복사하지 않았고, 글자(text 요소)와
글꼴을 쓰지 않았다. 파일마다 같은 내용의 `.attribution` 사이드카가 있다(`packages/engine/AGENTS.md` 7).
